# Йомайо — мод для Minecraft (Fabric 1.20.1)

Что добавляет:

- **Банка майонеза** — еда, всегда съедобная. Даёт на 30 секунд скорость II, прыгучесть II и свечение. Пустая банка (стеклянная бутылка) возвращается.
- **Майонезный блок** — батут: игрок отскакивает и не получает урон от падения.

## Рецепты

- Банка майонеза: яйцо + сахар + стеклянная бутылка (бесформенный крафт).
- Майонезный блок: 9 банок майонеза (3x3).

## Как собрать

Нужна Java 17.

1. Открой папку проекта в IntelliJ IDEA (Community подойдёт) как Gradle-проект и дождись синхронизации.
2. Запусти `Tasks -> build -> build` или в терминале: `gradle build`
   (если установлен Gradle 8.5+; свой wrapper можно создать командой `gradle wrapper --gradle-version 8.5`).
3. Готовый мод: `build/libs/yomayo-1.0.0.jar` (не `-sources`).
4. Положи jar в папку `mods` вместе с Fabric API 0.92.2+1.20.1.

Для теста прямо из IDE: `Tasks -> fabric -> runClient`.

## Структура

- `src/main/java/com/yomayo/` — код (`ModItems` регистрирует всё, `MayoBlock` — отскок, `MayoJarItem` — еда).
- `src/main/resources/assets/yomayo/` — модели, текстуры, переводы.
- `src/main/resources/data/yomayo/` — рецепты и лут.
